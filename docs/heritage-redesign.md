# 历史长卷与全站界面

本地首页为 `http://127.0.0.1:5173/`，文献库为 `/library`，整理入口为 `/workbench/ops`。端口以启动器打印的地址为准。

## 现行展陈

六章按时间向下展示 24 个关键节点，其余 52 条编年折叠为简表。检索与类型筛选覆盖完整资料。古代使用西北大漠、旧纸和低饱和建筑，包含灾荒、赋役与李自成起义；民国转为灰度，现代以朱红与生态绿色表现建设。生态治理直接放在现代时间线上，城市结尾为“仍在路上 · 今日榆林”，道路越过“续”标记渐隐进入城市画卷。

土路、石路、马路覆盖同一条连续 SVG 路径，按真实节点位置计算，转弯切线共享且纵向前进，材质交界重叠渐变。ResizeObserver 随检索结果、章节高度与窗口变化更新布局。缩略建筑逐节点匹配，背景与图片使用交叠的横向、纵向和径向遮罩，章节纸色按相邻章节实际颜色渐变，减少矩形边缘与硬切。介绍去掉白底边框，普通节点正文桌面 16px、手机 15px。

主题使用已有语义 token：朱红、墨色、旧纸、暗金与生态绿色。自托管 Noto Serif SC / Noto Sans SC 字体，正常中文字距，保留 SIL OFL 授权。主线为品牌展陈，资料查询为功能界面；VISUAL_VARIANCE=7、MOTION_INTENSITY=2、INFORMATION_DENSITY=6。

## 主题光标

桌面全站主光标由页面直接绘制：正文、标题、空白、图片与输入框为 32×42px 朱砂毛笔，按钮与链接切换为 32px 红色印章，点击产生 140ms 落印反馈。用户反馈原生 SVG 光标没有显示、只能看到伴随点，因此第八版移除小点，改为直接绘制完整矢量图形。笔尖与实际点击点对齐，位置不使用滞后过渡。绘制层 `aria-hidden`、`pointer-events:none`，不参与焦点和点击；输入插入点、文字选择与键盘操作不受影响。

绘制层使用 manual popover，进入浏览器顶层，打开节点或问答弹窗后也能显示在其上方。只有定位并显示绘制光标后才隐藏系统鼠标；离开页面、窗口失焦、触屏或组件清理会恢复原生回退。页面切换保留最后的鼠标位置，在新页面挂载后重新绘制，不需要等下一次移动。无 JS 或不支持顶层 API 时保留原生回退，避免出现完全没有光标的状态。

第九版重新绘制毛笔外形：细长竹杆、轻微圆柱明暗、竹节细纹、朱红束毫与尾口、米白笔毫及自然收尖的朱砂笔锋。笔身绕 `(2,2)` 旋转 38 度，保持原有热点与 32×42px 尺寸。页面绘制与静态回退采用同一形状；页面渐变使用现有主题 token，实例通过 useId 区分渐变定义。

第九版经真实浏览器截图确认毛笔轮廓、配色和笔尖定位，链接悬停仍切换为印章；控制台无错误，类型检查、lint 与 Node 构建通过。截图为 `screenshots/heritage-cursor-refined-v9.png`。

文献阅读页按钮修复：原 `.action` 的内边距与组件固定 32px 高度冲突，文字超出按钮底部。现改为自动高度、至少 44px、flex 居中及明确行高；共享此样式的工作台按钮一并受益。320、768、1280、1920px 下文字完整包含在按钮内且未超出视口，Tab 焦点可见，Node 构建通过。截图为 `screenshots/library-button-layout-fixed.png`。

触屏不绘制鼠标，减少动画模式保留实时定位的毛笔和印章、关闭落印与悬停过渡，高对比模式使用原生光标。指针移动以 requestAnimationFrame 合并，没有持续动画循环；切换页面清理监听和动画。组件为 `apps/web/features/heritage-cursor.tsx`，样式为 `apps/web/app/heritage-cursor.css`，静态回退资源在 `apps/web/public/images/cursors`。绘制图形使用现有颜色 token。

## 状态与操作

| 模块 | 操作与状态 |
| --- | --- |
| 历史长卷 | 目录、筛选、检索、折叠编年；无结果有恢复入口，接口不可用使用整理版资料并提示 |
| 节点讲解 | 正文、依据、原页、朗读与问答；原生弹窗约束焦点，Escape 关闭 |
| 文献库与阅读器 | 目录、识别状态、检索、分页、原页及文本版本；明确区分未识别与未校勘 |
| 史料助手 | 工具进度、来源、连续对话、停止和新对话；错误、资料不足与调用限额有提示 |
| 工作台 | 材料选择、页码、批次状态与记录；未填写令牌时提示输入，中文文案无字面问号乱码 |

模型检索遵守材料权利和公开可见性，撤回文本不会以旧初稿重新出现。未识别扫描页每轮最多临时读取两页，不自动写入发布成果。引文必须逐字连续匹配证据，失败时不展示成有效讲解；逐字匹配仍需要人工核验历史语义和 OCR。

## 资产与依据

建筑、沙漠、绿洲和城市图片均为展陈艺术意象。生成提示词、参考来源与资产路径保存在 `heritage-assets.json`、`heritage-assets-v2.json`、`heritage-landmarks-v2.json`、`heritage-assets-v3.json` 和 `heritage-assets-v4.json`，保留以便追溯。城市图参考陕西日报的榆林城区与榆溪河生态长廊实景，以楼宇、城区和道路为主，小面积绿带表现生态建设。

编年源数据为 `apps/web/features/history-timeline.json`，史料整理原稿为 `docs/榆林历史时间线.txt`；同步脚本 `scripts/seed_timeline.py` 保留人工节点与撤回状态。治沙指标依据 [国家林草局 2026-03-26 榆林治沙纪实](https://www.forestry.gov.cn/lyj/1/hmgzdt/20260326/665019.html)，为 860 万亩、90%以上与 30 倍，页面保留对应来源。Noto 字体来源为 [Noto CJK](https://github.com/notofonts/noto-cjk)。
